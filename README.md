# Pelha Car Oficina - site institucional

Site one-page da **Pelha Car**, oficina de funilaria, pintura e mecânica em São José - SC.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, depoimentos, faixa de orçamento, mapa, FAQ)
styles.css   # estilos (preto com o amarelo da marca)
script.js    # menu mobile, header ao rolar, animações de entrada, carrossel, FAQ
assets/      # favicon e fotos
```

Sem build: HTML, CSS e JS puros. Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.
